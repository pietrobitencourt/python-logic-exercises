## 🇧🇷 Português

### 📘 Sobre o repositório

Este repositório reúne a resolução de **listas de exercícios de lógica de programação e Python**, propostas na disciplina de **Programação de Computadores** do Centro Universitário do Distrito Federal (UDF).

Cada lista tem sua própria pasta, com o enunciado original, o código resolvido e um README específico detalhando o conteúdo abordado.

| 6 | lista-06-def | Funções (`def`) | ⏳ Não iniciada |

### 🧠 Conteúdos abordados no repositório

- Entrada e saída de dados, operações matemáticas básicas
- Estruturas condicionais (`if`, `elif`, `else`)
- Operadores relacionais e lógicos
- Laços de repetição (`while`, `for`)
- Estruturas de dados (listas, tuplas, dicionários, conjuntos)
- Funções (`def`)

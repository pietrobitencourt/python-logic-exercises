## 🇧🇷 Português

### 📘 Sobre

Este diretório contém a resolução da **Lista de Exercícios de Programação I**, proposta na disciplina de **Programação de Computadores** do Centro Universitário do Distrito Federal (UDF).

Os exercícios têm como foco consolidar os conceitos fundamentais da lógica de programação usando Python.

### 🧠 Conteúdo

A lista está dividida em três níveis de dificuldade:

**🔹 Nível 1 — Fundamentos (exercícios 1–10)**
- Entrada e saída de dados
- Operações matemáticas básicas
- Cálculos simples (soma, área, conversões)

**🔹 Nível 2 — Aplicações e Fórmulas (exercícios 11–20)**
- Cálculos mais elaborados
- Manipulação de variáveis
- Porcentagens e conversões
- Divisão inteira e resto

**🔹 Nível 3 — Lógica e Condições (exercícios 21–30)**
- Operadores relacionais
- Operadores lógicos (`and`, `or`)
- Validações e expressões booleanas

### ✨ Diferenciais

- Exercícios organizados por nível de dificuldade
- Código padronizado e comentado
- Foco em boas práticas para iniciantes

## 🇺🇸 English

### 📘 About

This directory contains the solutions to **Programming Exercise List I**, assigned in the **Computer Programming** course at Centro Universitário do Distrito Federal (UDF).

The exercises focus on consolidating the fundamental concepts of programming logic using Python.

### 🧠 Content

The list is divided into three difficulty levels:

**🔹 Level 1 — Fundamentals (exercises 1–10)**
- Data input and output
- Basic math operations
- Simple calculations (sum, area, conversions)

**🔹 Level 2 — Applications and Formulas (exercises 11–20)**
- More elaborate calculations
- Variable manipulation
- Percentages and conversions
- Integer division and remainder

**🔹 Level 3 — Logic and Conditions (exercises 21–30)**
- Relational operators
- Logical operators (`and`, `or`)
- Validations and boolean expressions

### ✨ Highlights

- Exercises organized by difficulty level
- Standardized, commented code
- Focus on beginner-friendly best practices

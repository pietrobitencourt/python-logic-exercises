## 🇧🇷 Português

### 📘 Sobre

Este diretório contém a resolução da **Lista de Exercícios de Programação II**, proposta na disciplina de **Programação de Computadores** do Centro Universitário do Distrito Federal (UDF).

Os exercícios têm como foco a prática de estruturas condicionais em Python (`if`, `if/else`, `if/elif/else`).

### 🧠 Conteúdo

A lista está dividida em três blocos, cada um restrito a uma estrutura condicional específica:

**🔹 Bloco 1 — Utilize apenas `if` (exercícios 1–10)**
- Verificações simples (maioridade, número positivo, par, febre)
- Comparações e condições únicas

**🔹 Bloco 2 — Utilize `if` e `else` (exercícios 11–20)**
- Decisões com dois caminhos (par ou ímpar, aprovado ou reprovado)
- Verificação de senha e validação de triângulo

**🔹 Bloco 3 — Utilize `if`, `elif` e `else` (exercícios 21–30)**
- Classificações com múltiplas faixas (conceito, IMC, faixa etária)
- Menus e simulações (calculadora, semáforo, pedra-papel-tesoura)

### ✨ Diferenciais

- Exercícios organizados por bloco, respeitando a estrutura condicional exigida em cada um
- Código padronizado e comentado
- Foco em boas práticas para iniciantes

## 🇺🇸 English

### 📘 About

This directory contains the solutions to **Programming Exercise List II**, assigned in the **Computer Programming** course at Centro Universitário do Distrito Federal (UDF).

The exercises focus on practicing conditional structures in Python (`if`, `if/else`, `if/elif/else`).

### 🧠 Content

The list is divided into three blocks, each restricted to a specific conditional structure:

**🔹 Block 1 — Use only `if` (exercises 1–10)**
- Simple checks (legal age, positive number, even number, fever)
- Comparisons and single conditions

**🔹 Block 2 — Use `if` and `else` (exercises 11–20)**
- Two-path decisions (even or odd, pass or fail)
- Password check and triangle validation

**🔹 Block 3 — Use `if`, `elif` and `else` (exercises 21–30)**
- Multi-range classifications (grade, BMI, age group)
- Menus and simulations (calculator, traffic light, rock-paper-scissors)

### ✨ Highlights

- Exercises organized by block, respecting the conditional structure required in each one
- Standardized, commented code
- Focus on beginner-friendly best practices
